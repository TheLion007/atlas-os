# Atlas OS 1.0.2

**Test of the automatic update.**

This version only exists to check that Atlas OS 1.0.1 finds a newer release, downloads it and installs it. It contains no change to the app compared to 1.0.1.

If you are on 1.0.1: open the **"New version available"** notice (or **Settings → Language and workspace → Check now**), click **Download**, then **Restart and install**. Your data in `%APPDATA%\Atlas OS` is kept.

If you are on 1.0.0: install `Atlas-OS-Setup-1.0.2.exe` by hand once (Windows SmartScreen: **More info**, then **Run anyway**). Updates are automatic from then on.

## 🇫🇷 En français

**Test de la mise à jour automatique.**

Cette version n'existe que pour vérifier qu'Atlas OS 1.0.1 trouve une version plus récente, la télécharge et l'installe. Elle ne contient aucun changement de l'application par rapport à la 1.0.1.

Si tu as la 1.0.1 : ouvre le message **« Nouvelle version disponible »** (ou **Paramètres → Langue et espace de travail → Vérifier maintenant**), clique sur **Télécharger**, puis sur **Redémarrer et installer**. Tes données dans `%APPDATA%\Atlas OS` sont conservées.

Si tu as la 1.0.0 : installe `Atlas-OS-Setup-1.0.2.exe` à la main une fois (SmartScreen de Windows : **Informations complémentaires**, puis **Exécuter quand même**). Ensuite, les mises à jour sont automatiques.
