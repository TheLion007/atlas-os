# Atlas OS 1.0.0

**Your personal command center for long, complex projects. 100% local: no account, no cloud, no data leaves your PC.**

First public release of Atlas OS for Windows.

## Highlights

- **Projects, plans, sub-projects, tasks and deadlines**, all linked together.
- **Calendar, Graph and Map** views of the same data, plus **Vault** (documents), **Timer**, **Notes** and **Work history**.
- **Local AI assistant (Ctrl+J)** through [Ollama](https://ollama.com): write things down loosely, review the proposed structure, create it in one click, undo in one click. Optional; nothing is sent over the internet.
- Command palette (Ctrl+K), three themes, sound profiles, interface in English and French.
- Your data lives in `%APPDATA%\Atlas OS` and is never touched by uninstalling.

## Install

1. Download **`Atlas-OS-Setup-1.0.0.exe`** below and run it.
2. Windows SmartScreen may say **"Windows protected your PC"**, because the installer is not code-signed yet. Click **More info**, then **Run anyway**.

Windows only for now. Version 1.0.0 does not update itself: from 1.0.1 on, the app checks GitHub for newer versions (it asks only for the latest version number and sends no data; you can turn it off in Settings).

## Report a problem

Open an [issue](https://github.com/TheLion007/atlas-os/issues/new/choose). Never attach your database.

## 🇫🇷 En français

**Ton centre de pilotage personnel pour des projets longs et complexes. 100 % local : pas de compte, pas de cloud, aucune donnée ne quitte ton PC.**

Première version publique d'Atlas OS pour Windows.

### L'essentiel

- **Projets, plans, sous-projets, tâches et échéances**, reliés entre eux.
- Vues **Calendrier, Graphe et Carte** des mêmes données, plus le **Coffre** (documents), le **Minuteur**, les **Notes** et l'**Historique de travail**.

1. Télécharge **`Atlas-OS-Setup-1.0.0.exe`** ci-dessous et lance-le.
2. Windows SmartScreen peut afficher **« Windows a protégé votre PC »**, car l'installateur n'est pas encore signé numériquement. Clique sur **Informations complémentaires**, puis sur **Exécuter quand même**.

Windows uniquement pour l'instant. La version 1.0.0 ne se met pas à jour toute seule : à partir de la 1.0.1, l'application regarde sur GitHub s'il existe une version plus récente (elle ne demande que le numéro de la dernière version et n'envoie aucune donnée ; désactivable dans les Paramètres).
