# Atlas OS 1.0.1

**New: automatic updates.** Atlas OS can now tell you when a newer version is available, and install it in two clicks. You can turn this off in Settings.

## What's new

- **"New version available"** notice: when a newer version exists, you click **Download**, then **Restart and install**. Nothing is downloaded or installed without your click.
- **Settings → Language and workspace**: a **"Check for updates automatically"** switch (on by default), the installed version, the state of the check, and a **Check now** button.
- The app checks at launch, then every few hours.
- **Your data is never touched** by an update (`%APPDATA%\Atlas OS` stays exactly as it is).
- Clear messages in English and French when something goes wrong: no connection, no published version, interrupted download, incomplete file.
- Documentation in English and French (README, contributing guide, desktop app guide).

## Privacy

The update check contacts GitHub **only to learn the number of the latest version**. It sends no data of yours (no projects, no notes, no identifier). Every other request from the app's window is still blocked: nothing else leaves your PC. Switch the check off in Settings if you prefer.

## Install

1. Download **`Atlas-OS-Setup-1.0.1.exe`** below and run it.
2. Windows SmartScreen may say **"Windows protected your PC"**, because the installer is not code-signed yet. Click **More info**, then **Run anyway**.

**Coming from 1.0.0?** Version 1.0.0 cannot update itself, so install 1.0.1 by hand once (over your current install: your data is kept). From then on, updates arrive by themselves.

`latest.yml` and the `.blockmap` file attached to this release are what the app reads to update itself; you do not need to download them.

## 🇫🇷 En français

**Nouveau : les mises à jour automatiques.** Atlas OS peut maintenant te prévenir qu'une version plus récente existe, et l'installer en deux clics. Tu peux le désactiver dans les Paramètres.

### Nouveautés

- Message **« Nouvelle version disponible »** : quand une version plus récente existe, tu cliques sur **Télécharger**, puis sur **Redémarrer et installer**. Rien n'est téléchargé ni installé sans ton clic.
- **Paramètres → Langue et espace de travail** : un interrupteur **« Vérifier les mises à jour automatiquement »** (activé par défaut), la version installée, l'état de la vérification, et un bouton **Vérifier maintenant**.
- L'application vérifie au lancement, puis toutes les quelques heures.
- **Tes données ne sont jamais touchées** par une mise à jour (`%APPDATA%\Atlas OS` reste exactement tel quel).
- Des messages clairs en français et en anglais quand quelque chose ne va pas : pas de connexion, aucune version publiée, téléchargement interrompu, fichier incomplet.
- Documentation en français et en anglais (README, guide de contribution, guide de l'application de bureau).

### Confidentialité

La vérification contacte GitHub **uniquement pour connaître le numéro de la dernière version**. Elle n'envoie aucune donnée de toi (ni projets, ni notes, ni identifiant). Toute autre requête de la fenêtre de l'application reste bloquée : rien d'autre ne quitte ton PC. Désactive la vérification dans les Paramètres si tu préfères.

### Installer

1. Télécharge **`Atlas-OS-Setup-1.0.1.exe`** ci-dessous et lance-le.
2. Windows SmartScreen peut afficher **« Windows a protégé votre PC »**, car l'installateur n'est pas encore signé numériquement. Clique sur **Informations complémentaires**, puis sur **Exécuter quand même**.

**Tu viens de la 1.0.0 ?** La version 1.0.0 ne peut pas se mettre à jour toute seule : installe la 1.0.1 à la main une fois (par-dessus ton installation actuelle : tes données sont conservées). Ensuite, les mises à jour arriveront toutes seules.

`latest.yml` et le fichier `.blockmap` joints à cette release sont ce que l'application lit pour se mettre à jour ; tu n'as pas besoin de les télécharger.
